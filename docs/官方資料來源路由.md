# 官方資料來源路由（Official Source Routing）

**Budget Review Skill v1.3 專用補充文件**

這份文件解決一個常見問題：

> **同樣都是「官方資料」，到底哪一個才是這個問題的 Source of Record？**

Budget Review Skill v1.3 不再只要求「找官方來源」，而是要求 LLM 先判斷問題類型，再去對應的正式系統取數。

分析框架仍然是：

> **Amount × Timing × Dependency × Execution**

但在分析前新增一層：

> **Official Source Routing → 再進入分析框架**

---

# 1. 核心原則：官方來源也有分工

不得簡化成：

> 主計總處 > 立法院 > 其他來源

因為不同機關掌握的是不同階段的正式事實。

例如：

- 行政院原編多少：行政院主計總處較接近 Source of Record
- 立法院最後刪多少、凍多少、決議理由：立法院才是 Source of Record
- 實際執行多少：各機關會計報表、決算、主計資料
- 審計後認定：審計部
- 某標案是否流標、何時決標：政府電子採購網

因此要依「問題」選來源，而不是只排一條固定可信度階級。

---

# 2. 中央政府預算：第一層官方入口

## 2.1 立法院預決算知識庫

網址：
https://lis.ly.gov.tw/budgetc/budgetkmout

適合查：

- 中央政府總預算案
- 中央政府法定總預算
- 追加／減預算
- 特別預算
- 第二預備金
- 單位預算
- 立法院總預算案審查專輯
- 行政院中央政府總決算
- 審計部中央政府總決算審核報告

定位：

> **中央政府預決算歷史資料的 Primary Index**

特別適合跨年度比較與追溯舊資料。

---

## 2.2 行政院主計總處：中央政府總預算及附屬單位預算

網址：
https://www.dgbas.gov.tw/cp.aspx?n=3623&s=1208

適合查：

- 各年度中央政府總預算案
- 各年度法定預算
- 追加（減）預算案
- 法定追加（減）預算

此頁將「預算案」「法定預算」「追加減預算案」「追加減預算」分欄列示，適合確認同一年度預算版本。

定位：

> **行政院預算版本與法定預算彙整入口**

---

# 3. 中央政府各機關：單位預算、決算、會計月報

## 行政院主計總處「中央政府各單位預算及附屬單位預算連結平台」

網址：
https://www.dgbas.gov.tw/News_hyperlink.aspx?n=3778&sms=11496

此平台對中央各機關提供：

- 公告預算網址
- 公告決算網址
- 公告會計報表網址

注意：平台本身是「索引／公告入口」，實際文件通常位於各機關官網，且連結由各機關主計人員維護。

適合查：

### Amount

- 某機關單位預算書
- 某計畫／科目原編與法定預算
- 決算數

### Timing

- 每月會計報表
- 經費累計表
- 預算執行狀況
- 年度內何時出現追加、調整或可動支變化

### Execution

- 累計實現數
- 分配預算
- 保留款
- 年度執行進度

---

# 4. 地方政府預決算

## 行政院主計總處「直轄市及縣（市）總預算及附屬單位預算」

網址：
https://www.dgbas.gov.tw/News_hyperlink.aspx?n=3783&sms=11499

此平台提供各縣市：

- 公告預算網址
- 公告決算網址

平台由主計總處提供，但實際預決算連結由各地方政府主計單位維護。

定位：

> **地方政府正式預決算入口索引**

如果分析台北市、新北市、桃園市、台中市或其他地方政府，不應直接套中央政府資料路由，而應先從此處找到該地方政府正式預決算來源。

---

# 5. 刪減、凍結與最終理由：立法院議事資料

若問題是：

- 最終到底刪多少？
- 最終凍多少？
- 哪一筆最後通過？
- 刪凍理由是什麼？
- 原始提案最後改成什麼？
- 朝野協商後結果如何？

應優先使用：

## 立法院議事暨公報資訊網（PPG）

網址：
https://ppg.ly.gov.tw/ppg/

優先尋找：

1. 最終院會資料
2. 預算審查總報告
3. 各委員會審查報告
4. 朝野協商紀錄
5. 最終決議文字
6. 後續解凍報告／解凍案

硬性規則：

> **行政機關預算書可以證明「原本編什麼」，但不能取代立法院文件證明「最後刪凍了什麼」。**

---

# 6. 實際執行與年度結果

若問題是：

- 去年到底花多少？
- 某筆預算真的沒花完嗎？
- 執行率多少？
- 年底是否突然集中支出？

優先順序：

1. 各機關正式會計報表／月報
2. 各機關決算書
3. 中央政府總決算
4. 審計部總決算審核報告

不要只拿「法定預算」當成「實際支出」。

---

# 7. 採購與廠商影響

若有人主張：

- 廠商不敢投標
- 流標變多
- 標案被迫延後
- 年底突然大量招標
- 預算不確定造成履約壓力

優先查：

## 政府電子採購網

網址：
https://web.pcc.gov.tw/

可核對：

- 招標公告
- 決標公告
- 公告日期
- 截止投標日
- 預算金額
- 招標方式
- 是否重複公告／流標後再招標
- 決標日期
- 決標金額

若要寫「廠商不敢投標」，最好進一步取得投標家數、流標率、重複招標或其他可量化證據；查不到時，只能標示為利害關係人主張或具體風險。

---

# 8. 通膨與成本變化：不得機械式套 CPI

政府預算跨年比較時，物價因素有時重要，但不能把所有支出直接乘上一個 CPI。

應先判斷支出性質。

## 一般物價

可參考行政院主計總處 CPI。

## 工程與營造

優先參考：

### 營造工程物價指數（CCI）

網址：
https://www.stat.gov.tw/Statistics.aspx?CaN=460&n=3906

官方資料另提供材料、砂石、混凝土、鋼筋、型鋼、鋼板與勞務等細項指數。

## 進口設備

可能需要考慮：

- 匯率
- 進口物價
- 特定設備市場價格

## 人事

應優先看：

- 法定調薪
- 員額變化
- 薪資制度

## 補助

應確認：

- 補助公式
- 每人／每件補助標準
- 服務量或受益人數變化

硬性規則：

> **只有在支出內容與該物價指數有實質關聯時，才可做實質價格調整。**

# 9. Source Routing Matrix

| 問題 | Primary Source | Secondary / Cross-check |
|---|---|---|
| 今年原編多少 | 主計總處預算案、機關單位預算案 | 立法院預決算知識庫 |
| 最終法定預算多少 | 主計總處法定預算、立法院法定預算資料 | 交叉核對兩者 |
| 最後刪多少／凍多少 | 立法院最終審查報告、院會決議 | PPG 協商紀錄 |
| 最終刪凍理由 | 立法院最終決議文字 | 審查總報告、協商紀錄 |
| 原始提案內容 | 委員／黨團正式提案 | PPG 審議資料 |
| 去年實際花多少 | 機關決算、中央政府總決算 | 審計部審核報告 |
| 月／季執行情況 | 機關會計報表／月報 | 主計相關執行資料 |
| 追加／減預算 | 主計總處、立法院預決算知識庫 | 法定文件 |
| 凍結何時解 | 解凍案、立法院正式文件 | 機關解凍報告 |
| 地方政府預決算 | 主計總處地方平台 → 各地方政府 | 地方議會正式文件 |
| 廠商／標案影響 | 政府電子採購網 | 機關採購資料 |
| 工程成本通膨 | CCI | 細項材料／勞務指數 |
| 一般物價 | CPI | 依支出內容再選更精確指數 |

# 10. 資料新鮮度（Freshness）規則

官方系統更新速度不一定一致。

因此：

1. 先確認文件日期與版本。
2. 若主計總處尚未刊登最新法定預算，但立法院已完成三讀，涉及「最新三讀結果」時應以立法院最終文件為主。
3. 待主計總處正式刊登法定預算後，再交叉核對。
4. 不得因某官方平台尚未更新，就把較新的另一個官方正式文件視為不可信。

硬性規則：

> **Source of Record 取決於「問題類型＋程序階段＋更新時點」，不是固定機關排名。**

---

# 11. 搜尋失敗時的 Fallback

若 Primary Source 找不到：

1. 先換同一機關的其他正式入口。
2. 查預決算知識庫或機關官網 PDF。
3. 查最終院會／審查報告／決算等相鄰正式文件。
4. 才使用政府新聞稿或政治人物說明作為線索。
5. 新聞與社群只能用來找關鍵字，不可取代正式文件。

若仍找不到，明確標示：

> **「目前未取得足以確認此項事實的正式資料。」**

不得猜測。

---

# 12. LLM 回答時應附的來源資訊

至少提供：

- 文件／資料庫名稱
- 發布機關
- 年度或日期
- 該來源用來證明哪一項事實
- 可核對連結

不要只丟一串網址而不說明每個來源的用途。

---

# 13. 最終心法

先問：

> **我要證明的是哪一種事實？**

再問：

> **哪個機關在這個程序階段擁有這項事實的正式紀錄？**

最後才開始做：

> **Amount × Timing × Dependency × Execution**
