# 官方資料來源路由（Official Source Routing）

**Budget Review Skill v1.4 專用資料來源規範**

這份文件回答一個最基本但最容易出錯的問題：

> **我要證明這件事，應該去哪個官方來源找？**

核心原則：

> **Source of Record 不是固定機關排名，而是「問題類型 × 程序階段 × 更新時點」。**

---

# 1. 中央政府歷史預決算

## 立法院預決算知識庫
https://lis.ly.gov.tw/budgetc/budgetkmout

適合查：

- 中央政府總預算案
- 法定總預算
- 追加／減預算
- 特別預算
- 第二預備金
- 單位預算
- 立法院預算審查專輯
- 中央政府總決算
- 審計部總決算審核報告

定位：**中央政府預決算歷史資料 Primary Index**。

---

# 2. 中央政府原編、法定與追加減預算

## 行政院主計總處：中央政府總預算及附屬單位預算
https://www.dgbas.gov.tw/cp.aspx?n=3623&s=1208

適合查：

- 預算案
- 法定預算
- 追加／減預算案
- 法定追加／減預算

注意：若最新年度主計總處尚未更新法定版本，而立法院已完成三讀，問題若是「最新三讀結果」，應先採立法院正式文件並說明更新狀態。

---

# 3. 中央各機關預算、決算、會計報表

## 主計總處：中央政府各單位預算連結平台
https://www.dgbas.gov.tw/News_hyperlink.aspx?n=3778&sms=11496

適合進入各機關查：

- 單位預算
- 單位決算
- 會計月報／相關會計報表

主要用途：

- 歷年實際執行
- 月／季 Timing
- 累計實現數
- Use-of-Funds 的分類決算與實際支出證據

---

# 4. 地方政府預決算

## 主計總處：直轄市及縣（市）總預算及附屬單位預算
https://www.dgbas.gov.tw/News_hyperlink.aspx?n=3783&sms=11499

這是地方政府正式資料入口索引。

應從此進入各直轄市、縣市政府自己的：

- 預算
- 決算
- 主計公開資料

不得直接把中央政府程序與資料來源假定為地方政府完全相同。

---

# 5. 最終刪凍、理由、協商與解凍

## 立法院議事暨公報資訊網（PPG）
https://ppg.ly.gov.tw/ppg/

適合查：

- 最終院會資料
- 審查總報告
- 最終決議
- 朝野協商紀錄
- 解凍報告／解凍案件

如果要回答：

> 「最後到底刪多少？」

或：

> 「為什麼最後凍結？」

PPG 的最終正式資料通常比立委原始提案或新聞更適合作為 Source of Record。

---

# 6. 採購、決標與流標

## 政府電子採購網
https://web.pcc.gov.tw/

適合查：

- 招標公告
- 決標公告
- 預算金額
- 決標金額
- 投標／流標／廢標相關資訊
- 重複招標
- 公告與決標時間

注意：

> **政府電子採購網不是所有政府支出的完整流向資料庫。**

補助、獎助、慰問、人事、轉撥、部分非採購支出不能僅靠採購網還原。

# 7. Use-of-Funds：歷年錢花去哪裡

v1.4 新增支出用途資料路由。

## 問：「依法／依預算可以花在哪裡？」

Primary Source：

1. 法規
2. 作業要點／支用規定
3. 預算書用途說明
4. 正式計畫文件

證據類型：**Budgeted Purpose**。

只能證明「可以／預計花在哪」，不能直接證明實際支出。

---

## 問：「某年度實際花多少？」

Primary Source：

1. 單位決算
2. 中央政府總決算／地方總決算
3. 機關會計報表
4. 審計報告

證據類型：**Actual Expenditure**。

---

## 問：「主要花在哪些方向？」

依優先順序查：

1. 決算中可辨識的用途分類與金額
2. 機關正式支用報告／業務報告／年報
3. 立法院解凍或專案報告中的主要支用情形
4. 採購、補助、受款等可公開資料

若只有官方列出的主要案例，證據類型屬於 **Reported Use**，不能自行推算整體占比。

---

## 問：「錢給了誰？」

先判斷支出類型。

### 採購

→ 政府電子採購網、決標公告、契約／成果資料。

### 補助／獎助

→ 機關依法公開的補助名單、受款清冊、政府資料開放平台、專案公開資料。

### 委辦

→ 採購決標、委辦計畫、成果報告、決算。

### 人事

→ 決算用途別、人事統計；不得自行推論未公開個人薪資明細。

### 機密／依法限制公開支出

→ 查法規、年度總額、公開用途、審計／監督資料。

若沒有公開逐筆資料，不得假裝可以完整重建每筆對象。

---

# 8. Use-of-Funds 的公開粒度標記

每年度資料都應標記：

| 等級 | 意義 |
|---|---|
| L1 | 日期、金額、對象、用途等逐筆資料 |
| L2 | 有分類金額，沒有完整逐筆 |
| L3 | 只有主要用途／部分案例 |
| L4 | 只有年度總額 |
| L5 | 未公開／依法受限制 |

硬性規則：

> **不能用 L3 資料寫成 L1 的確定程度。**

---

# 9. 審計資料

當問題是：

- 實際支出是否符合規定
- 決算是否有缺失
- 是否經法定監督查核

應找：

- 審計部總決算審核報告
- 機關相關審計資料
- 立法院預決算知識庫中的審計報告索引

注意：

> **「審計機關可查核」不等於「一般公眾可取得所有逐筆明細」。**

---

# 10. 工程物價與通膨

## 營造工程物價指數（CCI）
https://www.stat.gov.tw/Statistics.aspx?CaN=460&n=3906

工程／營造支出的跨年實質比較，應優先考慮 CCI 或更細項材料、勞務指數。

不得機械式用 CPI 調整所有政府預算。

其他支出應依內容找：

- 一般消費性支出 → CPI 或相關分類指數
- 進口設備 → 匯率、進口物價、設備市場價格
- 人事 → 法定調薪、員額、薪資制度
- 補助 → 每人／每件補助基準與服務量

---

# 11. 資料新鮮度檢查

每個官方資料使用前確認：

- 年度
- 發布／更新日期
- 預算案或法定版本
- 三讀前或三讀後
- 是否有追加／減預算
- 是否有後續解凍
- 若問用途，資料是「預算規劃用途」還是「當年度實際支出」

如果兩個官方來源不一致，先檢查是否是不同程序階段或更新時點，不要直接挑對自己論點有利的數字。

建議先列：

|---|---|---|---|
| 行政院原編 | | | Budget |

| 歷年決算 | | | Actual expenditure |
| 主要用途 | | | Budgeted / Reported / Actual |
| 採購影響 | | | Procurement |

# 一句核心規則

> **不要問「哪個官方網站比較權威」，要問「我要證明的這件事，在哪個程序階段由誰留下正式紀錄」。**
