# 使用說明

**Version 1.3 — Official Source Routing + Amount × Timing × Dependency × Execution**

這份文件是給「想直接拿來用」的人看的。

如果你只是想讓 ChatGPT 或其他 LLM 幫你查一則政府預算爭議，最簡單的方法是把 [`SKILL.md`](../SKILL.md) 或 [`政府預算刪凍查核_ChatGPT_LLM操作規範.md`](./政府預算刪凍查核_ChatGPT_LLM操作規範.md) 交給模型，再用下面的 Prompt。

---

# 最簡單的 Prompt

```text
請依照 Government Budget Review Skill v1.3 查核以下政府預算爭議：

【我要查的說法】
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

不要先下政治結論。

第一步先做 Official Source Routing：
針對「原編預算、最終刪減／凍結、最終理由、歷年決算、年度內執行、採購影響」分別指出應使用哪個官方 Source of Record，並確認資料年度、版本與更新日期。

接著分析：
1. Amount：歷年法定預算、實際執行、今年原編、法定、刪減、凍結、追加減。
2. Timing：預算什麼時候真正可以使用。
3. Dependency：被刪科目是否為其他支出的必要前置，有沒有替代方案或其他合法財源。
4. Execution：最後是否有實際資料證明服務、採購、工程或人力受到影響。

請將影響分成：
- 已證實影響
- 具體風險
- 利害關係人主張

所有百分比都必須標示分母。
如果資料找不到，請寫「未取得／目前無法確認」，不要猜測。
請附可核對的正式來源與每個來源的用途。
```

# 如果你只有一則新聞

直接貼新聞，再加：

```text
不要直接摘要這篇新聞。
請把新聞中的預算說法視為待查證主張，先做 Official Source Routing，再回到正式預算、立法院決議、決算與執行資料核對。
```

---

# 如果新聞說「被砍 XX%」

加：

```text
請確認 XX% 的分母是整個機關、單一計畫還是某個科目。
如果不同分母會得到不同百分比，請全部列出。
```

---

# 如果新聞把刪減與凍結一起算

加：

```text
禁止把刪減與凍結相加後稱為「被砍」。
兩者分開列出，並查凍結的正式解凍條件與解凍時間。
```

---

# 如果爭議是「立委提案砍掉某預算」

加：

```text
請把「原始提案」「協商／審議過程」「最後三讀結果」分開。
原始提案不得描述成最終刪減結果。
最終刪凍與理由請優先查立法院最終院會、審查總報告與正式決議。
```

---

# 如果有人說「去年不能比」

加：

```text
請先檢查去年是否為異常基準年：有無追加減預算、大額凍結／解凍、延遲通過、一次性大型支出、組織改制或科目重分類。
若有，請往前比較 2–3 年，不要只看去年。
```

---

# 如果有人要求「納入通膨」

加：

```text
不要機械式用 CPI 調整所有預算。
請先分類支出性質：一般消費、工程、進口設備、人事、補助等，再選擇具有實質關聯的物價或成本指標。
工程支出優先考慮 CCI 或材料／勞務細項。
```

---

# 如果爭議是「才刪 5%，怎麼可能有影響？」

加：

```text
請做 Critical Dependency Analysis。
不要用預算占比直接推論影響大小。
請確認被刪科目的具體產出、下游依賴、法律／契約／技術必要性、替代方案、其他合法財源，以及下游是否真的停止或延後。
```

---

# 如果爭議是「少了這筆就整個癱瘓」

加：

```text
請把「沒有 A 科目就整體不能做」視為待驗證主張。
要求建立 A → 下游工作 → 最終成果的依賴鏈，並檢查替代方案與其他合法資源。
如果只能證明有風險，請不要寫成已經癱瘓。
```

---

# 如果有人說「廠商不敢投標」

加：

```text
請不要只引用訪談或機關說法。
請優先查政府電子採購網，檢視投標／流標／重複招標／決標時點等資料。
如果沒有可量化證據，將此說法標為「具體風險」或「利害關係人主張」。
```

---

# 如果有人說「年底突然拿到很多錢，只能亂花」

加：

```text
請查各機關會計報表、月／季執行率、Q4 支出與招標決標是否集中、保留款及實際成果。
不要只因為追加或解凍較晚就直接推論年底亂花。
```

---

# 如果有人說「人才都跑了」

加：

```text
請查正式人力資料，例如缺額率、離職率、約聘續約、招聘與人力異動。
若沒有資料，不得把「人才外流」寫成已證實影響。
```

# 怎麼判斷 LLM 有沒有照規則做？

回答後快速檢查：

- 有沒有先說每個數字從哪個 Source of Record 取得？
- 有沒有確認文件是預算案還是法定版本？
- 有沒有檢查資料日期與是否已更新？
- 有沒有至少比較 2–3 年或說明為何只看一年？
- 有沒有實際執行／決算？
- 刪減跟凍結有沒有分開？
- 百分比有沒有分母？
- 最終理由是不是正式決議？
- 有凍結時有沒有查解凍條件與時間？
- 有延遲／追加時有沒有做 Timing？
- 小科目可能卡整案時有沒有做 Dependency？
- 有沒有查替代方案？
- 有沒有用實際執行資料驗證影響？
- 有沒有把合理風險誤寫成已發生事實？

缺太多項，代表查核還沒做完。
