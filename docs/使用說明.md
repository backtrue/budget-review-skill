# 使用說明

**Version 1.4 — Official Source Routing + Amount × Timing × Dependency × Use-of-Funds × Execution**

這份文件是給「想直接拿來用」的人看的。

最簡單的方法，就是把 [`SKILL.md`](../SKILL.md) 或 [`政府預算刪凍查核_ChatGPT_LLM操作規範.md`](./政府預算刪凍查核_ChatGPT_LLM操作規範.md) 交給 ChatGPT／Claude／Gemini 等模型，再照你的問題直接問。

---

# 最簡單的用法

```text
請依照這份 Government Budget Review Skill 查核以下政府預算問題：

「＿＿＿＿＿＿＿＿＿＿＿＿」

請先做 Official Source Routing，優先回到正式預算、決算、立法院決議、會計、採購、審計或其他對應的 Source of Record。

資料不足時請寫明無法確認，不要猜測。
```

# 如果你要查「被砍多少」

```text
請區分刪減與凍結，不要相加後直接稱為被砍。

請列出：
- 前 2–3 年法定預算與實際執行／決算
- 今年原編
- 今年三讀後法定預算
- 刪減金額與占原編比例
- 凍結金額與占原編比例
- 凍結解凍條件與時間

原始提案不得當成最終結果。
```

---

# 如果新聞寫「刪了 XX%」

```text
請特別確認 XX% 的分母是整個機關、單一計畫還是某個預算科目。
如果不同分母會得到不同結果，請全部列出。
```

---

# 如果去年可能是異常年

例如去年有追加預算、重大解凍、延遲通過、組織改制或一次性大型支出：

```text
不要只拿去年當唯一比較基準。
請往前看至少 2–3 年，並說明去年是否屬於異常基準年。
```

---

# 如果爭議是「預算太晚通過」

```text
請不要只比較年度總額。
請建立 Timing：
- 預算何時完成法定程序
- 未完成前依法如何執行
- 追加／解凍何時發生
- 經費何時真正可動支
- 年度還剩多少執行時間

不得把「預算沒過」簡化成「照去年預算花」。
```

---

# 如果爭議是「才刪 5%，怎麼可能有影響」

```text
請執行 Critical Dependency Analysis。

確認：
1. 被刪科目的具體產出
2. 哪些下游工作依賴它
3. 依賴是法律、契約、技術還是行政前置
4. 有沒有替代方案
5. 有沒有其他合法財源或既有資源
6. 沒有它，下游是否真的不能執行

不要用預算占比直接判斷影響大小。
```

# v1.4：如果你要查「歷年花費方向」

例如：

- 總統府國務機要費歷年花費方向
- 某部會宣傳費歷年花去哪裡
- 某基金補助對象怎麼變
- 某機關委辦費主要流向哪些工作

直接用：

```text
請依照 Budget Review Skill 的 Use-of-Funds Analysis，整理「＿＿＿＿」歷年花費方向。

請先做 Official Source Routing，再把資料分成：

1. Budgeted Purpose：法規／預算允許或預定用途
2. Reported Use：機關正式公開說明的實際用途
3. Actual Expenditure：決算、會計、採購、補助、受款或審計資料可核對的實際支出
4. Public Disclosure Level：每年度公開資料能看到逐筆、分類金額、主要案例、只有總額，還是未公開

請建立歷年表格。
不要把預算用途當成實際支出，也不要從少數案例推算整體占比。

若涉及機密或依法不公開項目，請區分「監督機關可查核」與「一般公眾可取得逐筆資料」。

資料不足時直接標示無法確認，不要猜測。
```

# Use-of-Funds 回答應長這樣

| 年度 | 法定預算 | 決算 | 公開可確認用途 | 證據類型 | 公開粒度 |
|---|---:|---:|---|---|---|
| 20XX | | | | Budgeted / Reported / Actual | L1–L5 |

公開粒度：

- **L1**：逐筆資料
- **L2**：分類金額
- **L3**：主要用途／部分案例
- **L4**：只有總額
- **L5**：未公開／依法受限制

如果模型只有 L3 資料，卻回答得像知道所有逐筆流向，代表它沒有照規則做。

# 如果有人說「廠商不敢投標」

```text
不要只引用官員、廠商或新聞說法。
請查政府電子採購網，至少比較投標家數、流標／廢標、重複招標、決標時間與履約期。
```

---

# 如果有人說「年底突然拿到錢，只能亂花」

```text
請查月／季預算執行率、Q4 支出與決標是否集中、保留款與實際成果。
把制度上的風險和已經發生的結果分開。
```

---

# 如果有人說「人才都跑了」

```text
請把人才流失當成待驗證主張。
查缺額率、離職率、招聘、續約或其他正式人力資料。
沒有資料時只能列為具體風險或利害關係人主張。
```

---

# 怎麼檢查模型有沒有照規則做？

至少快速看：

- 有沒有先選正確 Source of Record？
- 有沒有確認資料年度、版本與更新日期？
- 有沒有把提案誤寫成通過？
- 有沒有把刪減與凍結混在一起？
- 百分比有沒有寫分母？
- 是否只拿異常的去年比較？
- 有 Timing 問題時有沒有建立時間軸？
- 小科目被刪時有沒有檢查 Dependency？
- 問花費方向時，有沒有區分 Budgeted / Reported / Actual？
- 有沒有標示公開粒度？
- 有沒有拿少數案例推算整體用途占比？
- 有沒有把「可能影響」寫成「已證實影響」？

# 最後記住

這套 Skill 不是要 AI 替你決定預算該不該刪。

它先做的是：

> **找對資料 → 算對金額 → 看懂時間 → 找出依賴 → 分清預定用途與實際支出 → 驗證最後結果。**

剩下的政治價值判斷，再由你自己決定。
