# 政府預算刪凍查核 Skill

一套給 ChatGPT、Claude、Gemini、Agent 與其他 LLM 使用的政府預算查核規則。

它的目的不是替任何政黨、政府或政治人物辯護，而是要求 AI 在討論「預算被砍」「預算被凍」「某政策做不下去」以前，先把真正的預算事實整理清楚。

> **不要只問「砍了多少」，要問：相較於什麼、刪凍了哪裡、最後為什麼刪凍，以及最後真的少了什麼。**

---

## 為什麼需要這個 Skill？

每逢政府預算審查，新聞與社群常會快速出現這類說法：

- 「某預算被砍 XX 億」
- 「某項預算遭刪 80%」
- 「立委提案刪光某筆預算」
- 「某機關因為預算遭砍，所以業務做不下去」

問題是，這些句子往往少了最重要的上下文。

例如：

- 今年原本編多少？
- 去年法定預算是多少？
- 去年實際又花了多少？
- 「刪減」與「凍結」各是多少？
- 凍結要怎麼解凍？
- 新聞講的是原始提案，還是最後三讀結果？
- 刪凍理由是提案人的理由，還是最後通過的決議文字？
- 所謂「刪 80%」的分母，是整個部會，還是某一個小科目？
- 最後到底有哪一項服務、名額、採購、工程或時程真的受到影響？

這個 Skill 就是把這些問題固定化，讓 LLM 不要只跟著新聞標題或政治說法走。

---

## 核心原則

### 1. 一定要建立歷史基準

至少比較：

1. 去年法定預算
2. 去年實際執行／決算
3. 今年原編預算
4. 今年三讀後法定預算

只知道「今年原編 10 億、最後剩 8 億」，還不足以判斷這 8 億到底夠不夠。

### 2. 刪減與凍結完全分開

**刪減**代表預算真的減少。

**凍結**代表經費仍存在，但動支受到條件限制。

不得把「刪 10%＋凍 30%」直接寫成「預算被砍 40%」。

### 3. 提案不等於通過

立委原始提案、黨團提案、委員會討論版本，都只能用來說明審議過程。

若要回答「最後到底刪了多少」，必須回到三讀結果、審查總報告、朝野協商結論與最終決議。

### 4. 刪凍理由以最後決議為準

不能因為某位提案人在最初提案中寫了某個理由，就直接說「立法院因為這個理由刪除預算」。

### 5. 百分比一定要說分母

「某計畫被刪 80%」與「該機關總預算只少 0.8%」可能同時成立。

所以任何百分比都必須回答：**占誰的多少？**

### 6. 先看刪的是什麼，再看刪多少

人事費、法定義務支出、既有服務、新增政策、一次性採購、工程、宣傳費，即使刪減金額一樣，實際影響也可能完全不同。

### 7. 最後才判斷實際影響

不能從「刪了 30%」直接跳到「業務一定停擺」。

應建立：

**預算科目 → 實際業務 → 歷年執行 → 本年工作量 → 剩餘經費 → 可量化影響**

## 怎麼使用？

### 方法 A：直接把規範交給 ChatGPT / LLM

把 `SKILL.md` 或完整操作規範上傳到你的 Project、Workspace、Knowledge、Agent 或其他可長期讀取文件的環境。

然後直接問：

> 請依照政府預算刪凍查核規範，查核「○○預算被砍 XX%」這個說法。請區分刪減與凍結、確認最終三讀結果，並比較去年法定預算與去年實際執行。

### 方法 B：每次分析時直接附上 `SKILL.md`

適合沒有長期知識庫或 Skill 機制的 LLM。

### 方法 C：整合進自己的 Agent / MCP / 自動化流程

如果你的 Agent 具備網路搜尋或政府資料庫查詢能力，可以把 `SKILL.md` 當成固定分析規格，要求每次預算查核都依照同一套流程輸出。

## 建議提問範例

### 查一則新聞

> 請用這個 Skill 查核：「文化部某預算遭刪 90%」是否精確。不要只看新聞，請找最終三讀資料。

### 查刪減與凍結

> 幫我查某機關今年到底被刪多少、凍多少。兩者分開計算比例，並列出凍結解凍條件。

### 查「業務做不下去」是否成立

> 某機關表示因預算被刪，所以某服務無法繼續。請比較去年實際執行、本年度剩餘法定預算與工作量，確認這個因果關係能不能成立。

### 查政治攻防

> 請把「原始提案」「協商過程」「最後三讀結果」分成三段，不要把任何提案當成最後通過結果。

## 資料來源原則

本 Skill 建議優先順序：

1. 法定預算、三讀資料、審查總報告、正式決議
2. 決算與預算執行資料
3. 行政機關官方說明
4. 政黨、立委與政治行為者說明
5. 新聞報導
6. 社群貼文

新聞、政黨、政府新聞稿與政治人物說法都可以是重要線索，但在完成正式文件核對以前，應先視為**主張**，而不是自動當成事實。

## 適用範圍

目前版本主要以**台灣中央政府與立法院預算審議語境**設計，因此使用了「三讀」「凍結」「解凍」「審查總報告」「朝野協商」等用語。

核心方法仍可延伸到地方政府或其他國家的預算制度，但應依當地法定預算程序修改資料來源與審議流程。

---

## 這個 Skill 不做什麼？

它不會替你決定：

- 某筆預算「應不應該刪」
- 哪一個政黨比較合理
- 哪一方的政治價值觀比較正確

它先做的是更前面的工作：

> **先把預算事實整理完，再判斷政治論述是否成立。**

如果基本數字、分母、最終決議與實際影響都還沒搞清楚，就還不到急著下政治結論的階段。
